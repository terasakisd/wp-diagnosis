ボタン式の質問に答えるとおすすめの結果を表示する診断ツールを、カスタム投稿で複数作れるWordPressプラグイン。

== 説明 ==

カードローン診断、保険診断、投資商品診断など、用途を問わず横展開できる汎用診断ツールです。
1つの「診断」がカスタム投稿として独立しており、質問・選択肢・結果アイテム・除外ルールはすべて診断ごとに管理画面のUIから編集できます。

= 主な機能 =
* 複数の診断を作成可能（カスタム投稿）
* 質問・選択肢をUIで追加/削除/並び替え
* 表示項目（金利、限度額、保険料など）を診断ごとに自由定義
* 結果アイテム（金融機関、保険会社など）をUIから登録
* 「Q◯で◯を選んだら◯◯を非表示」という除外ルールをUIで設定
* 「Q◯で◯を選んだら指定順で先頭に表示」という並び替えルールをUIで設定
* ショートコードで埋め込み

= 使い方 =
1. 管理画面「診断ツール → 新規追加」で診断を作成
2. メタボックスのタブで「質問項目」「表示項目」「結果アイテム」「除外ルール」「並び替えルール」を設定
3. ショートコードを固定ページに貼り付け
   - 診断フォーム用: `[wpd_diagnosis id="123"]`
   - 結果表示用: `[wpd_diagnosis_result id="123"]`
4. 「基本設定」タブで結果ページを指定

= ショートコード属性 =
* `id`（必須）: 診断の投稿ID
